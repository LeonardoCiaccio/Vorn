Flusso Backup — Singolo File

01
▶Apro il programma di backup
02
📁Seleziono la cartella sorgente
es. /progetti/moduli
03
🔍Il programma scansiona la cartella
elenca tutti i file presenti
04 — CONTROLLO
Esiste già un .index.json nella cartella?
NO — primo backup
Genera UUID v4 per ogni file trovato
Crea .index.json vuoto
SÌ — backup successivo
Carica l'indice esistente in memoria
05
🧮Calcola SHA-256 del contenuto di A.md
hash = SHA256(byte del file) — solo contenuto, niente metadati
06 — CONTROLLO
L'hash coincide con "current.hash" nell'indice?
SÌ — file non cambiato
Nessuna operazione.
Passa al file successivo.
NO — file nuovo o modificato
Procedi con il salvataggio
07 — CONTROLLO
L'hash esiste già nello store?
stesso contenuto già backuppato da un altro progetto?
SÌ — deduplicazione
Non scrivere nello store.
Il file esiste già — risparmio spazio.
NO — file nuovo nello store
Costruisci oggetto:
header (metadati) + contenuto
Scrivi in store/ con nome = hash
08
📝Aggiorna .index.json
— aggiorna "current": { name, hash }
— appendi voce in "history": { hash, name, ts, machine, bytes }
09
✓File backuppato
Store aggiornato — Indice aggiornato — Storia preservata
